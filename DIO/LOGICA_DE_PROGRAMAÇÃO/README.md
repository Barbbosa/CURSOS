# Curso de Lógica de Programação

Este repositório contém os exercícios desenvolvidos durante o curso de **Lógica de Programação**, realizado durante o estágio na  Acadmemia Nacional de Polícia como parte do desenvolvimento técnico proposto pela empresa.

## Sobre o curso

O curso teve como objetivo consolidar conceitos fundamentais da programação, com foco em:

- Variáveis
- Operadores
- Laços de repetição
- Estruturas de decisão
- Funções

## Observação sobre o certificado

⚠️ **Este curso não possui certificado de conclusão.** Isso ocorreu porque o curso foi realizado utilizando uma conta que não era a minha, sendo assim não foi possível emitir o certificado em meu nome. Apesar disso, o curso foi **concluído integralmente**, incluindo todos os módulos e exercícios propostos.
