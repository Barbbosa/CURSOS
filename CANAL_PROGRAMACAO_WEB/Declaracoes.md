# JavaScript: Sintaxe e Declarações

O javascript é uma serie de declarações que fazemos que é interpretada por um navegador

## Pode conter
- Valores
- Operadores
- Expressões
- Funções
- Comentários

## Declarações

O ponto e vírgula (`;`) é utilizado para separar declarações no JavaScript.

Exemplo:

```javascript
let a, b, c;
a = 5;
b = 6;
c = 7;
```

O JavaScript não obriga o uso do ponto e vírgula em todas as declarações, mas é recomendado utilizá-lo para deixar o código mais claro e evitar ambiguidades.

## Espaços em branco

O JavaScript geralmente ignora espaços em branco desnecessários.

Exemplo:

```javascript
console.log("Olá, mundo!")         ;
```

A formatação pode variar sem alterar o resultado, desde que a sintaxe continue válida.

## Quebra de linha

O JavaScript aceita quebras de linha. O interpretador identifica o fim de uma declaração conforme as regras da linguagem, mesmo quando não há ponto e vírgula explícito.

## Sintaxe

Sintaxe é a maneira como o código deve ser escrito para que a linguagem consiga interpretá-lo corretamente.
